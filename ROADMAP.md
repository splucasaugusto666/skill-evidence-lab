# Roadmap

- v0.1: instruction-only library, strict static profile, deterministic catalog, local installer, baseline evaluation protocol.
- v0.2 proposed: general spec validator via maintained upstream library, registry schema, explicit user-scoped installation, trusted provenance, SkillParity integration tests.
- v0.5 proposed: authoring factory, routing/composition with conflict checks, behavioral runner and independent scoring, broader security evaluation.
- v1.0 goal: stable documented interfaces, actual runtime evidence, repeatable evaluation results, signed releases and validated integrations. Do not promote a version merely to meet a schedule.
